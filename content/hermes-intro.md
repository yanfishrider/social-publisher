# Hermes Agent — 你的本地 AI 助手

> 开源、本地运行、真正能干活

---

## 一、Hermes 是什么

Hermes Agent 是由 Nous Research 开源的本地 AI Agent 框架。它不是聊天机器人，而是一个能**实际操作工具完成任务**的智能代理——读写文件、执行命令、浏览网页、管理日程，AI 直接动手而不只是动嘴。

---

## 二、核心能力

### 工具驱动，不只是聊天

Hermes 内置数十种工具，AI 可以直接调用：

- **文件系统**：读写、搜索、编辑文件
- **终端**：执行命令、运行脚本、管理进程
- **浏览器**：导航网页、点击交互、截图分析
- **网络**：搜索、提取网页内容
- **记忆系统**：跨会话持久化用户偏好和知识

### 技能系统，积累经验

每次解决一个复杂问题，可以保存为「技能」——下次遇到同类任务自动加载，越用越聪明。支持创建、编辑、删除技能，形成个人知识库。

### 定时任务

支持 Cron 表达式驱动的定时任务，可搭配技能和工具自动执行周期性工作，如每日报告、定期检查、数据采集。

### 多平台接入

通过 Telegram、Discord、微信等渠道接入，随时随地与 Hermes 交互。支持多 Profile 隔离不同场景。

### 扩展生态

插件系统支持自定义工具和技能，可接入任何 API 或本地服务。开源社区持续贡献新的能力模块。

## 三、与 ChatGPT 等云服务的区别

| 能力 | Hermes Agent | ChatGPT / Claude |
|------|-------------|-----------------|
| 本地运行 | 是 | 否 |
| 执行终端命令 | 是 | 否 |
| 操作浏览器 | 是 | 否 |
| 读写本地文件 | 是 | 否 |
| 定时任务 | 是 | 否 |
| 技能积累 | 是 | 否 |
| 隐私保护 | 完全本地 | 数据上传云端 |

Hermes 不是取代它们，而是互补——云模型负责思考和推理，Hermes 负责把思考变成实际行动。

## 四、典型使用场景

- **自动化开发**：代码审查、测试、部署一条龙
- **内容创作与发布**：从素材整理到多平台分发全自动
- **智能客服**：接入 Coze 工作流 + 微信通知，实现自动问答与人工转接
- **数据分析**：连接数据库、执行查询、生成报告
- **定时监控**：定期检查服务状态、采集数据、发送通知
- **个人助理**：管理日程、处理邮件、维护笔记

## 五、技术架构

```
用户 → Telegram/Discord/微信/CLI
         │
         ▼
      Hermes Gateway（消息路由 + 多 Profile）
         │
         ▼
      AI Model（本地 Ollama 或云端 API）
         │
         ▼
      工具层（文件/终端/浏览器/网络/记忆/技能/定时任务）
```

支持多种模型后端：OpenAI、Anthropic、DeepSeek、本地 Ollama 等，灵活切换。

## 六、快速开始

```bash
# 安装
pip install hermes-agent

# 初始化配置
hermes setup

# 启动 CLI 对话
hermes chat

# 接入 Telegram
hermes gateway start
```
